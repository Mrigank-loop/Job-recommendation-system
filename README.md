💼 Job Recommendation System

An ML-powered web application that recommends jobs based on user skills using text similarity and ranking algorithms.

🚀 Features

## Features

- Skill-based job recommendations
- Match score calculation
- Salary estimation
- Job descriptions

🎯 How It Works

User enters skills (e.g., Python, SQL, Machine Learning).

The system compares input skills with job skill sets using CountVectorizer and Cosine Similarity.

Jobs are ranked by match percentage.
The best matching roles are displayed in an interactive dashboard.
